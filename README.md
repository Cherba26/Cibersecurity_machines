#  Cybersecurity Write-ups

Este repositorio contiene mis **write-ups** y soluciones de máquinas de ciberseguridad (Hack The Box, TryHackMe, LetsDefend, CyberDefenders, etc.).

El objetivo es documentar mi aprendizaje y mantener un registro de las técnicas y metodologías que voy aprendiendo. 

Conforme avance irán apareciendo nuevas plataformas, campos y áreas de estudio.

---

##  Estructura y Contenido

- **`/blue-team`** — Orientado a la defensa, análisis forense y respuesta ante incidentes.
- **`/red-team`** — Orientado a pentesting, hacking ético y explotación.
- **`/cyberdefenders`** — Retos y análisis de laboratorio específicos de CyberDefenders.
